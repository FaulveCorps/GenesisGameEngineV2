# Genesis Game Engine - Build Instructions

## Prerequisites
- Windows 10/11
- Visual Studio 2022 Community Edition
- CMake 3.16+
- vcpkg (for dependency management)

## Quick Start

### 1. Configure
```powershell
cd c:\Users\jpfau\Desktop\Project\GenesisGameEngine
cmake -B build -G "Visual Studio 17 2022" -DCMAKE_TOOLCHAIN_FILE="C:/Program Files/vcpkg/scripts/buildsystems/vcpkg.cmake"
```

### 2. Build All Targets
```powershell
cmake --build build --config Debug
```

### 3. Run Unit Tests
```powershell
ctest -C Debug --test-dir build --output-on-failure
```

### 4. Run Sample Game
```powershell
cd build\GameProjects\SampleGame\Debug
.\SampleGame.exe
```

### Auto-cycle and artifacts
You can run `SampleGame` in an automated renderer cycle mode which will switch renderers N times and save software framebuffer screenshots to `artifacts/`:

```powershell
.\SampleGame.exe --gfx-order software --auto-cycle 5 --auto-interval 1000
```

Screenshots and test outputs are saved into the `artifacts/` directory (ignored by default).
## Build Targets

| Target | Type | Location | Purpose |
|--------|------|----------|---------|
| EngineCore | Static Library | `build/Engine/Core/Debug/EngineCore.lib` | Core engine with renderer, scene, ECS |
| SampleGame | Executable | `build/GameProjects/SampleGame/Debug/SampleGame.exe` | Demo application |
| UnitTests | Executable | `build/tests/Debug/UnitTests.exe` | 4 unit tests with Catch2 |

| asset_packer | Tool | `build/Tools/asset_packer/Debug/asset_packer.exe` | Asset compression utility |
| shader_compiler | Tool | `build/Tools/shader_compiler/Debug/shader_compiler.exe` | Shader preprocessing tool |

## Detailed Build Commands

### Build Specific Target
```powershell
cmake --build build --config Debug --target SampleGame
cmake --build build --config Debug --target UnitTests
```

### Build with Verbose Output
```powershell
cmake --build build --config Debug --target UnitTests -- /v:detailed
```

### Rebuild from Clean
```powershell
cmake --build build --config Debug --clean-first
```

## Key Technologies

### Engine Core
- **Graphics**: OpenGL (runtime-resolved via SDL3)
- **Window Management**: SDL3
- **ECS**: EnTT (header-only)
- **Models**: Assimp (3D model loading)
- **GUI**: ImGui integration stub

### Testing
- **Framework**: Catch2 (amalgamated single-header mode)
- **Coverage**: Engine init/shutdown, model loading, ECS operations, plugin manager

### Build System
- **Generator**: Visual Studio 17 2022 (MSVC)
- **Dependency Discovery**: Manual vcpkg paths (SDL3, Assimp, EnTT)
- **Testing**: CTest integration
- **Packaging**: CPack (ZIP format)

## Troubleshooting

### Issue: Tests Not Found by CTest
**Solution**: Ensure `enable_testing()` is in root CMakeLists.txt and tests/CMakeLists.txt contains `add_test()`.

### Issue: "Cannot open program database" (Catch2 build)
**Solution**: Already fixed - using Catch2 amalgamated single-header mode avoids library PDB contention.

### Issue: SampleGame Won't Start
**Solution**: Ensure you run from the correct directory (build/GameProjects/SampleGame/Debug) where assets are post-copied.

### Issue: GL Function Pointers Undefined
**Solution**: Ensure SDL3 is linked and GL functions are resolved via `SDL_GL_GetProcAddress` at runtime.
